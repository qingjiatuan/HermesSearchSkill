## 💻 典型调用示例

### 1. PubMed 运动医学文献检索
```python
# pip install metapub
from metapub import PubMedFetcher

fetch = PubMedFetcher()
# 搜索肌肉肥大相关研究
pmids = fetch.pmids_for_query("muscle hypertrophy resistance training", retmax=50)

for pmid in pmids[:10]:
    article = fetch.article_by_pmid(pmid)
    print(f"{article.title}")
    print(f"  期刊: {article.journal}")
    print(f"  发表: {article.year}")
```

### 2. OpenAlex 批量文献搜索（推荐！完全免费无限制）
```python
# pip install pyalex
from pyalex import Works

# 搜索力量训练相关研究
papers = Works() \
    .search("strength training periodization") \
    .filter(publication_year="2020-2024") \
    .sort(cited_by_count="desc") \
    .get(100)

for p in papers[:10]:
    print(f"[{p['cited_by_count']}次引用] {p['title']}")
```

### 3. Semantic Scholar 获取引用关系
```python
import requests

url = "https://api.semanticscholar.org/graph/v1/paper/search"
params = {
    "query": "exercise physiology adaptations",
    "limit": 20,
    "fields": "title,authors,citationCount,abstract"
}

response = requests.get(url, params=params)
results = response.json()['data']

for paper in results:
    print(f"[{paper['citationCount']}] {paper['title'][:80]}...")
```

### 4. Crossref DOI 元数据批量获取
```python
# pip install habanero
from habanero import Crossref

# 添加邮箱可获得更高速率限制
cr = Crossref(mailto="your.email@example.com")

result = cr.works(
    query = "sports performance recovery",
    filter = {"from-pub-date": "2020-01-01"},
    limit = 50
)

for item in result['message']['items']:
    print(f"{item['title'][0]}")
```

## 💡 数据获取实用技巧

### 免费获取付费文献的方法
- **Unpaywall**: 浏览器插件，自动检测开放获取版本，合法合规
- **Google Scholar 按钮**: 右侧常有作者上传的PDF链接
- **ResearchGate/Academia.edu**: 直接发私信向作者索要（成功率80%+）
- **预印本平台**: 很多论文正式发表前已在 arXiv/bioRxiv 免费发布
- **作者个人主页**: 大学教授个人主页通常有已发表论文PDF

### 批量获取最佳实践
- **元数据优先**: 先用 Crossref/OpenAlex 批量获取文献列表和引用关系
- **摘要筛选**: 使用 PubMed/Semantic Scholar 获取摘要进行初筛
- **全文定向**: 筛选出关键文献后再逐个获取全文
- **尊重速率限制**: 免费API通常有QPS限制，建议添加 `time.sleep(1)` 避免被封

### 文献管理工具
- **Zotero**: 免费开源，支持插件扩展，自动抓取文献元数据
- **Mendeley**: Elsevier旗下，免费基础版
- **EndNote**: 行业标准，收费软件

## ⚠️ 注意事项

1. **版权合规**: 批量爬取请遵守各平台 robots.txt 和服务条款
2. **速率限制**: 免费API通常有限速，建议添加延时避免被封IP
3. **引用规范**: 使用开源数据时请引用原始数据源
4. **数据质量**: 预印本未经同行评审，结论需谨慎对待
5. **API Key 安全**: 不要将API Key硬编码在公开代码中
